Solmar — an open-world crime game in the browser. Rook drives a sun-soaked coastal city: steal and drive five cars, outrun the Solmar City Police through a five-star wanted system with named pursuit units and a helicopter, run 8 story missions with a three-person crew, fight on foot with five weapons and a weapon wheel, pick up fares, hunt 12 hidden Sun Medallions, upgrade cars in the garage, and climb from ROOKIE to KINGPIN. Everything runs offline from static files — Three.js city, generative WebAudio radio, save/load, minimap and a dense HUD.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
